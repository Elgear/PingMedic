# PingMedic Privacy

PingMedic is a local Windows network diagnostics and troubleshooting application. It does not require a user account and does not include first-party analytics or telemetry.

## Local data

PingMedic may store user-configured target presets, speed-test history, and generated reports on the local computer. These files remain on the device unless the user chooses to copy or share them.

## Network requests

Some diagnostic features intentionally make network requests when the user runs them. Depending on the selected tool, these requests may contact:

- hosts, IP addresses, websites, or services selected by the user;
- public DNS resolvers used for DNS comparison;
- public IP or ISP metadata services used to display connection information;
- public LibreSpeed servers used for internet speed testing;
- local network hosts when the user runs LAN diagnostics or the Network Scanner.

Those external services can receive the network information normally associated with a request, including the user's public IP address. Their own privacy policies and logging practices apply.

## Reports

Diagnostic reports are created locally. PingMedic does not upload reports automatically. A report leaves the device only if the user chooses to share or upload it.

## Network scanning

The Network Scanner is intended for networks and systems the user owns or is authorized to test. Scan results are processed locally by PingMedic.

## Changes

This privacy notice may be updated as PingMedic gains new features or integrations. Material changes will be reflected in the public repository.
